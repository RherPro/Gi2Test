Esta é a página do projeto Git to Test (Gi2Text).
Por enquanto ela constrói um terminal e testa se uma string é reconhecida como um inteiro (/^[+-]?\\d+$/. em JavaScript) e se o valor é suportado por tipo inteiro sem sinal de 32 bits em linguagens que o tipo é habilitado.
Digite uma string de entrada para checá-la e receber uma saída.
A string '${}' não é reconhecida como inteiro.
A string '${}' como valor tipo inteiro não é suportado sem sinal de 32 bits.
A string '${}' como valor tipo inteiro é suportado sem sinal de 32 bits.
