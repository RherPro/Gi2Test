This is the Git to Test (Gi2Text) project page.
For now, it builds a terminal and tests whether a string is recognized as an integer (/^[+-]?\\d+$/. in JavaScript) and if it is supported by the 32-bit unsigned integer type in languages where it is enabled.
Enter a input string to check it and get output.
The string '${}' is not recognized as an integer.
The string '${}' as type integer value isn't supported as 32-bit unsigned.
The string '${}' as type integer value is supported as 32-bit unsigned.
